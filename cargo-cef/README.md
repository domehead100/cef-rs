# cargo-cef

This is a simple built/run helper, so you can do:

- `cargo cef run` to build and run the cefsimple example

- `cargo cef run cefsimple` to build and run the cefsimple example

- `cargo cef run osr` to build and run the osr example

- `cargo cef build` to build the cefsimple example

- `cargo cef build --release` to build the cefsimple example in release mode

- `cargo cef build osr` to build the osr example

- `cargo cef build osr --release` to build the osr example in release mode
